# iceberg (skill)

The rules, as a skill. Install with:

```bash
npx skills add hellohelen-ai/iceberg
```

Then say `/iceberg` if your agent does not pick it up on its own.

`SKILL.md` and `../../prompt.md` say the same thing. `prompt.md` is the short form the Claude Code hook injects every turn; `SKILL.md` is the long form an agent loads on demand.
